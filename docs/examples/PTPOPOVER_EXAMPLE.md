# PTPopover 示例清单

示例页面应覆盖以下场景：

- Basic custom View
- Automatic / top / bottom / leading / trailing placement
- UIViewController 内容
- Arrow 和 excluded hit region
- PTContextMenu、选中、禁用、危险操作、滚动菜单
- Multiple popovers 和 group replace
- Cell Anchor、滚动跟随和 Anchor 消失
- Keyboard、TextField、Dynamic Type、RTL、Dark Mode、VoiceOver
- Banner、Tips、Popover、Alert 和 Debug Overlay 的层级共存

当前仓库先提供可复用 API 和迁移文档；复杂宿主页面的视觉、手势和性能仍需业务工程执行设备回归。
