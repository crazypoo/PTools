## 迁移规则

1. 新代码优先使用“新入口”列；旧入口只用于兼容已有业务。
2. `PooToolsNetwork` 与 `PooToolsNetWork` 目前指向同一个实现，不能同时初始化两套网络单例。
3. 网络请求的动态 token、Header 和 Endpoint 应通过 provider 提供；Session 配置在 `Network` 初始化时固定。
4. 媒体模块使用 `PooToolsMediaCore` 的值类型和协议，不再为了图片或视频加载引入 Network。
5. 迁移时先替换编译期名称，再执行现有质量门禁；行为差异必须单独记录，不能靠重命名掩盖。

## 兼容窗口

- 5.x：保留所有既有公开符号和旧产品别名。
- 5.x 后续版本：新增入口只追加到 canonical API，不向旧动态入口扩散。
- 6.0.0：只有当迁移报告中所有调用方完成替换，并且删除门禁通过后，才删除旧入口。
