# PTools 5.62.0 CocoaPods → SwiftPM 迁移前置状态

> Status: `PENDING_BUILD_EVIDENCE`

## 中文

本文件记录 5.62.0 的迁移前置契约，不执行宿主项目迁移。

- `PooToolsWebKit` 对应旧 `PooTools/WebKit`，继续提供 `PTHTMLHeightCalculator`，不强制引入新的 `PToolsWeb`。
- `PooToolsVideoCache` 对应旧 `PooTools/VideoCache`，复用 `PTVideoFileCache` / `PTVideoManager`；视频先直接播放，缓存并行进行。
- `PooToolsFilterCamera` 对应旧 `PooTools/FilterCamera`，复用 `C7Collector`、`HarbethKit` 和 `MediaViewer`，不复制 FilterCamera 源码。
- `PooTools/Flag` 继续保留旧 Pod 入口，但 `FlagKit` 由宿主显式管理，不再由 PTools 隐式安装。
- `KTVHTTPCache` 不再属于 PTools 运行时依赖；PTools 不再使用代理服务器或 Bonjour Patch。

执行以下命令并完成 CocoaPods、SwiftPM 的 Debug / Release 与 iOS Simulator / 真机核心回归后，才能把状态改为 `READY_FOR_CONSUMER_MIGRATION`：

```bash
swift package dump-package
bash Scripts/validate_module_parity.sh --check
bash Scripts/validate_distribution_parity.sh
```

## English

This document records the PTools 5.62.0 migration-preparation contract. It does not migrate any host application.

- `PooToolsWebKit` is the SwiftPM compatibility product for `PooTools/WebKit` and keeps `PTHTMLHeightCalculator` available without requiring the newer `PToolsWeb` stack.
- `PooToolsVideoCache` is the SwiftPM compatibility product for `PooTools/VideoCache`; it reuses `PTVideoFileCache` / `PTVideoManager`, starts remote playback immediately, and caches in parallel.
- `PooToolsFilterCamera` exposes the existing `C7Collector`, `HarbethKit`, and `MediaViewer` implementation without copying source files.
- The historical `PooTools/Flag` Pod entry remains source-compatible, but `FlagKit` is host-owned and is no longer installed implicitly by PTools.
- `KTVHTTPCache` is no longer a PTools runtime dependency; no Bonjour or localhost proxy patch is required.

Change the status only after the package, CocoaPods, Simulator, and device evidence is complete.

## Español

Este documento registra el contrato de preparación para migrar PTools 5.62.0 de CocoaPods a SwiftPM. No migra ninguna aplicación anfitriona.

- `PooToolsWebKit` conserva `PTHTMLHeightCalculator` como producto de compatibilidad sin exigir la nueva pila `PToolsWeb`.
- `PooToolsVideoCache` reutiliza `PTVideoFileCache` / `PTVideoManager`, reproduce la URL remota de inmediato y almacena la caché en paralelo.
- `PooToolsFilterCamera` expone la implementación existente de `C7Collector`, `HarbethKit` y `MediaViewer` sin duplicar código.
- El subspec histórico `PooTools/Flag` sigue siendo compatible, pero `FlagKit` pertenece al host y PTools ya no lo instala implícitamente.
- `KTVHTTPCache` ya no es una dependencia de runtime de PTools; no se necesita ningún parche Bonjour o localhost.

El estado solo puede cambiar después de completar la evidencia de SwiftPM, CocoaPods, Simulator y dispositivo real.
