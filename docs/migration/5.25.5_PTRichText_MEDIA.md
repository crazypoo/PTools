# 5.25.5 PTRichText Rich Media 迁移说明

## 适用范围

5.25.5 面向 iOS 17+ / Swift 6+，把 `PTRichText` 的图片附件从 URL-only 扩展为统一 Rich Media Attachment。
`Any` 只存在于 MainActor UI 兼容边界，实际图片加载仍由 `PTLoadImageFunction` 负责。

## 图片

旧代码可以继续使用：

```swift
let oldText = PTTextAttribute.image(imageURL, .custom(size: CGSize(width: 32, height: 32)))
```

新代码建议使用：

```swift
@MainActor
let text = PTRichText.image(source: imageURL,
                            configuration: .init(estimatedAspectRatio: 1))
let loader = PTLoadImageFunction.makeRichTextMediaLoader()
titleLabel.pt_apply(richText: text, mediaLoader: loader)
```

`source` 可以复用 `PTLoadImageFunction.loadImage(source:)` 支持的来源。加载期间显示占位图，失败时显示 `failureImage`，
宿主复用或重新设置富文本时旧请求会被取消。

## 视频

```swift
@MainActor
let text = PTRichText.video(source: videoURL,
                            configuration: .init(
                                posterSource: coverSource,
                                showsPlayIcon: true,
                                showsDuration: true,
                                estimatedAspectRatio: 16.0 / 9.0))
titleLabel.pt_apply(richText: text,
                    mediaLoader: PTLoadImageFunction.makeRichTextMediaLoader()) { interaction in
    if case .media(.video(let id)) = interaction {
        // English: Hand playback to the host player.
        // Español: Entrega la reproducción al reproductor del host.
        // 中文：将播放交给宿主播放器。
        presentVideo(id: id)
    }
}
```

没有 `posterSource` 时，Loader 会调用 `PTVideoThumbnailService` 生成封面；有自定义封面时优先加载封面。
富文本不会持有 `AVPlayer`、`AVPlayerItem` 或完整视频数据。

## 兼容边界

- `UILabel` 和 `UITextView` 都使用静态封面附件；真正播放器由宿主、MediaBrowser 或系统播放器创建。
- 旧 URL 图片入口保留，不删除现有公开 API。
- 新增的媒体交互统一通过 `PTRichTextInteraction.media` 回调，不把闭包写入 `PTRichText` 值模型。
- 不实现 TextKit 2 inline player、自动播放、PiP、DRM、HLS 控制、音频或 Live Photo 附件；这些不属于 5.25.5 阻断范围。
