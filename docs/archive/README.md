# PTools 文档归档 / Documentation Archive / Archivo de documentación

## 简体中文

历史计划只有在仍然具有架构决策、迁移依据或发布证据时才进入这里。已完成但没有长期价值的临时计划不复制到归档目录；Git history 保留其追溯能力。

## English

Historical plans belong here only when they preserve an architectural decision, migration rationale, or release evidence. Completed temporary plans without long-term value are not duplicated; Git history remains the source for archaeology.

## Español

Los planes históricos solo se archivan aquí cuando conservan una decisión arquitectónica, una razón de migración o evidencia de release. Los borradores sin valor duradero no se duplican; Git mantiene la trazabilidad.
