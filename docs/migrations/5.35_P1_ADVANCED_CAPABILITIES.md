# 5.35.0 P1 迁移说明

5.35.0 新增能力均为可选模块，不改变 `PooTools/Core` 的默认安装入口，也不删除旧公开 API。

| 需求 | 推荐入口 | 安装 |
| --- | --- | --- |
| 主题 token | `PTTheme` / `PTThemeResolver` | `PToolsTheme` / `PooTools/Theme` |
| 页面加载和错误状态 | `PTContentState` / `PTContentStateView` | `PToolsContentState` / `PooTools/ContentState` |
| 表单 | `PTFormEngine` / `PTFormViewController` | `PToolsForm` / `PooTools/Form` |
| 通用 BLE | `PTBluetoothCentral` | `PToolsBluetooth` / `PooTools/Bluetooth` |
| 文档工作流 | `PTDocumentPickerCoordinator` | `PToolsDocuments` / `PooTools/Documents` |
| 确定性模拟 | `PTSimulationRuntime` | `PToolsSimulation` / `PooTools/Simulation` |
| 无障碍 | `PTAccessibilityFocusCoordinator` | `PToolsAccessibility` / `PooTools/Accessibility` |

## 迁移边界

- 现有 Input、Picker、Calendar、CheckBox、Slider 和 Stepper 可以逐步由 Form 的字段模型驱动；不要求一次替换旧 UI。
- 现有 Loading/HUD 不删除。ContentState 只统一状态，不强制某一种视觉表现。
- `PTBluetoothPermission` 仍负责权限；`PToolsBluetooth` 负责授权后的扫描、连接和 GATT。
- `PooToolsShare`、`PooToolsPDF` 仍可直接使用；Documents 只补齐文件生命周期和系统 picker/preview 桥接。
- Simulation 不替换 Simulator，也不接管生产服务；它只在显式启用时提供替身。

## Swift 6 注意事项

公共请求、事件、表单和结果模型使用 `Sendable` 值类型。UIKit、QuickLook 和 CoreBluetooth 对象只能停留在对应的 MainActor/系统对象边界。不要把 `Any`、`Progress`、UIKit 控件或 `CBPeripheral` 放入跨 actor 的业务模型。

## 验证清单

- Light/Dark、High Contrast、Dynamic Type、Reduce Motion、Reduce Transparency 和 RTL。
- 表单条件字段、异步校验取消、提交失败和键盘避让。
- BLE 扫描超时、连接取消、特征发现、通知、断连和重连。
- 文档多选、UTType、bookmark stale、安全作用域、QuickLook 和大文件导入。
- 模拟手动时钟、回放顺序、取消和默认关闭。
- SwiftPM/CocoaPods parity、iOS Simulator Debug/Release 和真实宿主回归。
