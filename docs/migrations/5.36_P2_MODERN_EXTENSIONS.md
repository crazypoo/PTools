# 5.36.0 P2 迁移说明

5.36.0 没有把新模块塞进 `PooTools/Core`，因此 Core 用户无需迁移。需要现代系统能力时，
按功能显式安装对应 SwiftPM product 或 CocoaPods subspec。

| 旧做法 | 5.36.0 做法 |
| --- | --- |
| 各页面直接创建 UIFeedbackGenerator | `PTHapticEngine.shared.play(_:)` 使用语义事件 |
| 各模块自行设置 AVAudioSession | `PTAudioSessionCoordinator` 统一设置和监听事件 |
| 各处读取 UserDefaults 并临时判断开关 | `PTConfigurationStore` + typed key + snapshot |
| Widget 代码猜 App Group 或直接刷新 | `PTWidgetSharedStore` 显式 group + reload coordinator |
| AppIntent 直接拼 URL 或绕过路由 | `PTAppIntentRouteDescriptor` → `PTRouteRequest` |
| 每个 Live Activity 自己处理 token/去重 | `PTActivityCoordinator` 统一生命周期和诊断 |

AppIntents、WidgetCore、Activities 应安装到对应 Extension Target，不要为了 App Target 的
普通 UI 把 extension-safe subspec 加入聚合依赖。现有公开 Core、Network、媒体和路由 API
保持不变。
