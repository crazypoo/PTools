# 5.36.1 P0/P1/P2 收口说明

5.36.1 是对 5.36.0 平台、能力和现代系统扩展的收口版本，重点是稳定契约、宿主接入和可验证性，
不是新的大功能版本。所有能力面向 iOS 17+ / Swift 6+，UIKit 仍由宿主 target 决定。

## P0 平台契约

- `PTConnectivitySnapshot` 新增 `supportsIPv4` 和 `supportsIPv6`，旧 JSON 缺字段时按 `false` 解码。
- `PTKeychainStorageAdapter` 只代理既有 `PTKeyChain`，不再创建第二套 Security 查询实现；旧的
  `PTKeychainStorage` 仍可编译但已 deprecated。
- 通知位置触发器使用 `PTNotificationLocationTrigger` 值快照，授权统一走 `PTPermissionNotification`。
- `PTRouteHostCoordinator` 按 `UIWindowScene` 处理 URL、Universal Link、NSUserActivity、Spotlight、
  通知和 AppIntent 路由，不读取全局 key window。
- `PTBackgroundTaskHostCoordinator` 负责启动前注册、调度、取消和后台 URLSession 恢复；标识与
  entitlement 仍由宿主维护。

## P1 能力契约

`PTContentConnectivityAdapter`、`PTBaseViewController.installContentStateHost`、
`PTFormViewController`、`PTFormFieldRendererRegistry`、`PTDocumentPDFBridge` 和生产 Provider
协议都属于可选模块。模拟器只替换 Provider，不替换生产协议；真实 BLE、位置、文档、无障碍和多 Scene
仍需宿主在设备上验收。

## P2 扩展契约

Core 只提供 `PTFeedbackCenter` 语义钩子；`PToolsFeedback` 可通过
`PTHapticEngine.installAsDefault()` 安装触觉适配器。AppIntent、Widget 和 Live Activity 示例位于
`Example/Extensions`，宿主必须建立独立 Extension Target、App Group、Associated Domains、
`APPLICATION_EXTENSION_API_ONLY=YES` 和隐私脱敏策略。

## 验收边界

Simulator 可验证源码、模块、包契约和无硬件测试；不能证明真实 BLE 外设、触觉、电源/中断、后台
生命周期、系统授权弹窗或锁屏视觉。未完成这些现场验收前，不创建 `5.36.1` tag。
