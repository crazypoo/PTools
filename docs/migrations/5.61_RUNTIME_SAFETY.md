# 从 5.60.x 迁移到 5.61.0

## 无需改动的兼容入口

- `PTNetworkSpeedTestFunction`、`PTPingTool`、旧 UserDefaults helper 和现有 Scene 兼容入口继续保留。
- Kakapos 不再是 PTools 的依赖；调用方不应再直接依赖 PTools 内部的 VideoX 类型。

## 推荐迁移

1. 将测速调用改为 `PTNetworkSpeedTestConfiguration` + `PTNetworkSpeedTester`，显式传入自有服务地址。
2. 将新 Ping 功能改为 `PTPingSession`，在页面退出时 `await stop()`。
3. 将通用持久化改为 `PTStorage`，按 module/feature 建立 namespace。
4. iPad/多窗口页面使用 `PTSplitViewController`，路由保持调用 `PTRouter`，不要自行判断 size class。
5. 只在系统对象跨回调边界时使用已登记的 `@unchecked Sendable` 包装器；业务模型使用快照。

## 发布检查

```bash
bash Scripts/report_5_61_runtime_safety.sh --check
bash Scripts/validate_5_61_release.sh
```

完成真实设备和宿主回归后，再创建不带 `v` 前缀的 `5.61.0` tag。
